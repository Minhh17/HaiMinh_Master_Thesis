# Hợp đồng tích hợp

Baseline là Ibex Demo System theo pin. Khi thay đổi, kiểm tra address decode,
request/grant/response, byte enables, reset polarity, clock crossing, IRQ route
và memory map C/linker. Mọi thay đổi phải có test và impact record.
[Memory map hiện tại](../../docs/design/memory-map.md) là source-derived, chưa verified trên board.
