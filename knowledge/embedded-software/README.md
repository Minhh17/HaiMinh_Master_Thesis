# Embedded software

Phạm vi CA02/CA05/CA06: startup code, linker script, bare-metal C, driver, interrupt và debug. Bắt đầu từ firmware upstream trong [simulation runbook](../../docs/guides/simulation.md).

Bài tập đầu: sau build thành công, tìm ELF entry, vùng text/data/stack trong map/disassembly rồi giải thích đường đi từ reset tới `main`. Chưa có ELF được build thì ghi NOT RUN, không chép một memory layout giả định làm baseline.
