# RISC-V ISA

Phạm vi CA01/CA02/CA06: semantics của lệnh được dùng, phần mở rộng được cấu hình, CSR/trap và calling convention. Nguồn mở đầu: [RV32I chính thức](https://docs.riscv.org/reference/isa/v20260120/unpriv/rv32.html).

Khi thêm note, ghi version specification và cấu hình/compiler flags đang xét. Đừng suy mọi phần mở rộng trong specification đều hiện diện ở core; đối chiếu pinned source và build configuration. [Learning plan](../README.md) xác định bài tập cần hoàn tất.
