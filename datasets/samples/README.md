# Tiny fixtures

Chưa có fixture. Chỉ thêm mẫu nhỏ đủ kiểm thử parser/reference model, có generator/seed hoặc quyền phân phối đã xác nhận, manifest và expected output độc lập. Ghi rõ `SYNTHETIC` cho dữ liệu sinh; không gọi đó là ADC measurement.

Phase 1 chưa cần fixture DSP. Dữ liệu radar thật và archive lớn nằm ngoài Git theo [dataset workflow](../README.md); không bỏ vào đây để né chính sách raw data.
