# Bibliography dùng chung

Nguồn chuẩn duy nhất là [research/literature/references.bib](../../research/literature/references.bib), hiện để trống có chủ ý vì chưa có record được xác minh đầy đủ. Khi thêm LaTeX/Markdown build, cấu hình đường dẫn tới file đó; không copy để chỉnh độc lập.

Mỗi citation key phải khớp [literature matrix](../../research/literature/literature-matrix.csv) và note có nguồn kiểm chứng. Chọn style theo quy định trường sau khi nhận template chính thức; hiện chưa giả định APA/IEEE hoặc hệ thống build luận văn.
